# Rules & Learning Guidelines

## 1. Language
- Hamari saari chat aur explanations **Hinglish** language mein hi hongi.

## 2. Theory First (Step-by-Step)
- Koi bhi topic start karne se pehle poori theory step-by-step samjhayi jayegi.
- Ek baar mein sab kuch nahi batana hai — thoda-thoda karke samjhaya jayega.
- Har point ke baad **mera (user ka) confirmation/understanding lena zaroori hai** agle point par jaane se pehle.

## 3. Practical Code Implementation (One Step at a Time)
- Jab code likhne ki baari aaye, tab **step-by-step (ek baar mein sirf 1 step)** follow hoga.
- Har step par mere doubts clear honge aur mere confirmation ke baad hi agle step par move karenge.

## 4. Final Notes (.md File)
- Topic fully complete hone ke baad last mein ek consolidated **.md Notes file** generate hogi.
- Notes file ke andar yeh sections zaroor honge:
    1. Concept Theory & Explanation
    2. Complete Step-by-Step Code
    3. Common Mistakes / Gotchas
    4. Interview Questions & Answers

## 5. Project Reference
- Code structure, naming conventions aur patterns ke liye `AndroidConcepts` project ke existing files ko reference ke taur par dekha jayega.
